# Security policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability, exposed credential,
authority bypass, publication bypass, or unsafe worker behavior.

Report it through
[GitHub private vulnerability reporting](https://github.com/AubreyF/aubtown/security/advisories/new).
Include the affected commit, the smallest reproducible case, the expected
authority boundary, and any evidence that a credential or external system was
reached. Do not include live credentials, personal data, or provider traffic in
the report.

## Supported version

The current `main` branch is the only supported version during the pilot. The
factory remains draft-publication-only and should be treated as pre-release
software.
